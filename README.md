# Java Day 69 – Employee Attendance & Payroll System

## Project Description
A Java-based employee management application that records employee attendance and calculates monthly salary based on the number of present days.

## Features
- Add employee records
- Generate employee IDs manually
- Prevent duplicate employee IDs
- Mark employees present or absent
- Display employee attendance
- Calculate salary based on attendance
- Generate monthly payroll

## Salary Calculation
Daily Salary = Monthly Salary / 30

Calculated Salary = Daily Salary × Present Days

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Scanner
- Exception Handling

## File
`Main.java`

## How to Run
1. Compile: `javac Main.java`
2. Execute: `java Main`

## Concepts Learned
Classes, objects, constructors, ArrayList, methods, searching, exception handling and calculations.

## Note
This is an educational project. Attendance records are stored in memory and are cleared when the program exits. The payroll calculation uses a simplified 30-day model, not actual statutory payroll rules.
